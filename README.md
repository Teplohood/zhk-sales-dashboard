# Продажи ЖК: исследовательский дашборд

Проект курса «Визуализация», вариант 1. Сделки с 2 марта по 30 сентября 2026 года: 248 проданных квартир из 367.

Дашборд: https://teplohood.github.io/zhk-sales-dashboard/

## На какие вопросы отвечает

| Вопрос | Где смотреть |
|---|---|
| Что происходит с продажами, какая динамика по неделям | «Сделок по-прежнему около восьми в неделю…» (квадраты по неделям, средний чек под месяцами) |
| Сколько заработали и сколько потеряли на скидках | KPI сверху и график «Выручка… Скидки…» по месяцам |
| Как продаются однушки, двушки, трёшки | рейтинг «Комнатность» на шахматке, цифры в клетках, фильтр по комнатности |
| Как продаются квартиры в разных корпусах | подписи корпусов под фасадами, клик по корпусу |
| Кому дать премию, с кем поговорить | график менеджеров с метками ▲ и ▼ |
| Какие квартиры продаются хорошо, а каким нужно помочь | рейтинг характеристик и пустые клетки на фасадах |

## Как устроен

Частица данных — сделка (дата, сумма, скидка, квартира, менеджер, дата обращения). Визуальный атом — клетка или квадрат, одна сделка.

- Основной график собран из фасадов корпусов: по вертикали этаж, по горизонтали квартиры в порядке номеров, ширина клетки пропорциональна площади. Закрашенная клетка обозначает сделку, цвет показывает срок от обращения до сделки, пустая клетка — квартиру в продаже. Над низкими корпусами стоит рейтинг характеристик: доля проданных по виду, комнатности, этажу, цене за м² и площади.
- Справа те же сделки разложены по неделям (стопки квадратов), месяцам (выручка и скидки) и менеджерам.
- Клик по клетке, корпусу, строке рейтинга, неделе, месяцу или менеджеру фильтрует остальные графики. Esc сбрасывает фильтры.

## Файлы

- `index.html`, `style.css`, `app.js`: дашборд (D3.js, без сборки)
- `data.js`: данные для дашборда, `data/`: исходный xlsx и csv
- `datalens-editor/`: версия основного графика для DataLens Editor (Advanced-чарт), неделя 6

Локальный запуск: `python -m http.server` в папке проекта, затем http://localhost:8000.
